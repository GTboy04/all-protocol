# R13 阶段交付：断线恢复与点位功能描述

2026-11-15 · 分支 `codex/r13-runtime-reliability`，承接现有 R11/R12 工作区。范围为 [R13](requirements/R13-runtime-reliability.md) 软件功能及用户追加的 [R20](requirements/R20-point-definitions.md)。现场与长时间验收独立记录。

## 已实现

- 设备连接区增加“断线恢复…”：自动重连默认关闭；初始/最大间隔 200–300000 ms、重试上限 1–100 次，间隔逐次加倍至上限。意外断线和临时连接失败可触发重试。
- 独立选择是否恢复断线前的读取轮询/OPC UA 订阅。重连建立新的会话 ID 与代次，旧事件隔离；手动单次请求、排队写入及未知结果写入均不恢复。
- 主动断开、取消连接、停止重试、断开全部、删除设备和关闭项目均取消重试并清理资源。“停止全部采集”同时清除等待恢复的读取任务。等待恢复的点表暂不可编辑，先停止采集后可修改。
- 显示等待重试、尝试次数/上限、下次重试时间及恢复失败原因。连接状态和恢复按钮的悬停提示包含最后成功通信时间。串口打开状态不表示所有站号可达，须查看各点采样质量。
- 配置/证书/权限类错误停止自动恢复；不切换证书、加密模式、身份或串口名称。
- OPC UA 发布保活、值通知和最后观察到的数值变化分别记录。活跃订阅的未变化数值不会仅因无新通知而过期；发布超时仍会过期。保活不更新采样/成功时间，也不将已过期、无效或断开的旧值标为刚采样成功。
- 点位多行功能描述、只读查看、按名称/地址/描述筛选、跨当前设备点表定位，以及 HTML/JSON 报告描述，详见 R20。

## 配置兼容

恢复配置以 `recovery_` 前缀的整数开关和数值写入设备连接字段，与协议连接/查询参数分开校验。没有自定义恢复配置的项目保持原版本；包含自定义恢复设置的项目使用配置 v6，SQLite 表结构仍使用 user_version 3。旧项目 v1–v5 可读取，默认关闭恢复；旧程序不应打开含恢复配置的 v6 项目。

只保存设置，不保存重试次数、待恢复任务、下次重试时间或采样值。重新打开项目不会自动联网。点位描述复用既有字段，无需升级点表格式。
