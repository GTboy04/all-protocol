# 多协议服务端设计

服务端采用同一工作台内的常驻协议标签。Modbus TCP 保留从站和点位配置，Siemens S7 使用 DB、M、I、Q 绝对地址表。页内按监听设置、点位、请求日志和报文顺序组织。标签持续显示协议名和监听状态，正在监听的标签还显示端口。

```text
返回首页     服务端工作台                           2 / 2 项监听中
Modbus TCP  监听中 :1502       Siemens S7  监听中 :1102
监听地址    端口   启动或停止                    方案状态   保存方案
点位表及编辑操作
请求日志与 RX / TX 报文
```

保留工作台墨蓝 `#142A40`、工作区灰蓝 `#EDF2F6`、白色面板 `#FFFFFF`、监听绿 `#154C47` 和过渡琥珀 `#896B3D`。界面用微软雅黑，端口与报文用 Consolas。状态常驻标签，方便切换后直接确认另一协议仍在监听。

- 每个标签持有独立的 I/O 会话，切换、返回首页及进入客户端只改变窗口焦点或可见内容。启动、停止和端口冲突按协议处理。关闭服务端工作台时先处理方案保存，再停止全部监听。关闭首页会关闭两种工作台，等待监听、已接受的 TCP 连接和后台线程退出。
- S7 默认监听 `127.0.0.1:1102`，可配置为 `102` 或其他可用端口。模拟一个经典 S7comm PLC。COTP 接受直连 TSAP，随后协商 PDU，处理 Read Var 和 Write Var。模拟数据支持 Byte、Int、Word、DInt、DWord、Real 和 Bool。I 区允许在服务端修改当前值以模拟输入，客户端写入 I 区会被拒绝。
- S7 的点位映射到实际字节。独立 Bool 可共用一个字节，整字节点位和 Bool 的占用不可重叠。监听时冻结配置，写入更新当前值，每次重新监听从初始值加载。S7 方案和请求日志单独存储。
- 开发前检查通过条件包括端口冲突可恢复、跨标签保持连接、退出释放两个端口，以及 Modbus 既有方案可加载。联调用应用客户端和独立 Snap7 客户端验证，协议测试覆盖区间、I 区写入、Bool 相邻位和错误回执。
