# R5 服务端统一契约

## 目标与依赖

依赖 R1。消除应用层对 Modbus TcpServer、ServerRequest 的具体依赖，为统一运行概览与场景模拟提供接口。

## 接口

定义 ServerAdapter：校验方案、bind、shutdown、读取/修改运行值。注册表提供协议键、工厂、能力描述和 UI 工厂。监听状态、生命周期事件和请求元数据采用通用信封，协议详情仍由适配器保留。

## 实现边界

ServerSession 只管理生命周期及错误，不生成某协议的日志记录。Modbus 从站/寄存器与 S7 内存模型继续独立；通用运行值接口用协议目标及类型化值传递，避免硬套同一地址模型。

存储继续读取旧方案和旧日志；通用事件新格式通过显式版本处理。协议注册集中在组装入口，ServerWorkbench 不再逐项写分支。

## 开发步骤

先写接口与两个适配器封装，再迁移 ServerSession、桥接和工作台，最后移除旧注入特例。该需求保持原有端口、读写语义与用户流程。

## 验收

应用层不再导入具体服务器；现有 Modbus / S7 服务端集成用例通过；启动失败、重复停止、同时监听、客户端退出和窗口关闭均释放资源。用最小假适配器证明接入不需修改通用会话。
