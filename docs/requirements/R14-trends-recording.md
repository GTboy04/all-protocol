# R14 · 实时趋势与会话录制

2026-11-15 · 状态：计划中，尚未实施。

## 目标与依赖

依赖 R2、R3、R4、R6、R10。利用统一采样事件，把当前值扩展为可对比、可保存、可离线查看的时间序列。建议在 R13 运行状态语义明确后交付。

## 首版范围

- 从点表选择多个点位加入趋势，支持跨设备对比、暂停画面、时间缩放、游标读数和图例。
- 数值绘制曲线，布尔量绘制阶梯图；首版 String 仅保留记录与事件列表，不绘制数值曲线。
- 原始值和工程值可切换，量纲不同的变量可分图或分轴；质量异常和断线区间明确标记，不跨缺口连接成有效曲线。
- 手动开始、停止一次录制，保存采样、质量、必要配置快照与操作事件；支持离线打开和 CSV 导出。
- 在时间线上标记写入、回读、故障启停和连接变化，并关联当时捕获的请求证据。

## 数据与实现

- 建立独立的录制存储，不复用最近 500 条请求日志作为采样历史。项目保存录制视图配置，录制数据使用独立、带版本的文件。
- 记录稳定设备/点位 ID、会话代次、接收时间、可用的源时间戳、原始值、质量及工程换算配置。区分事件接收时间和设备时间，不假设多设备时钟已经同步。
- 点位地址、类型或换算规则改变时分段记录，保留各段配置，避免用新倍率解释旧数据。
- 后台批量写入，使用有界缓冲；队列溢出、磁盘满和异常终止造成的缺失必须记录并展示。关闭时完成有限等待与清理。
- 画面按可见时间范围降采样，保留尖峰；显示降采样不改变已录制原始数据。仅消费现有采样流，不因打开趋势额外轮询设备。

## 分批交付

1. 多点实时趋势、质量标记和有界内存缓存。
2. 会话录制、离线查看、版本化文件与 CSV 导出，构成首版完整交付。
3. 扩展 R10 报告，在冻结快照中加入指定区间曲线和录制摘要；截图与数据使用同一时间范围。

## 边界

不在首版提供云端历史库、无限期保存或向真实设备重放录制写入。离线查看不会创建设备连接。订阅值未变化、未收到通知和确实缺失数据须按采集模式解释，不能混为一谈。

## 验收

- 混合协议、多设备、布尔量、浮点数、质量变化和断线均正确展示；不把保留的最后成功值画成新的有效采样。
- 录制过程中修改点位后，历史段仍能正确解释；离线查看不依赖本机数据库和当前项目配置。
- CSV 与录制数据条数、质量、时间范围一致，保留异常字符和明确时区；导出取消或失败不破坏已有文件。
- 按 R18 的固定负载记录界面响应、缓冲上限、磁盘增长和丢样情况。发生丢失时，画面与文件都能定位缺失区间。

## 交付物

趋势视图、录制文件格式说明、离线查看入口、CSV 导出、质量与存储失败测试，以及报告扩展记录。
