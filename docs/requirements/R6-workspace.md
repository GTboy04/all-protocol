# R6 项目工作区

## 目标与依赖

依赖 R2、R4、R5。将已具备的多设备、点表和模拟服务统一呈现，降低来回切窗口成本。

## 布局与流程

- 左侧项目树：设备→点表；模拟服务→协议实例。
- 中间当前设备视图：快速读写 / 点表监视；服务端视图：方案 / 当前值。
- 底部可折叠请求日志及报文详情；顶部显示连接数、监听数与异常数量。
- 切换视图不切断会话；支持从设备树定位异常。
- 首页与原本本地调试作为快捷入口继续可用。

## 状态与实现

设备运行状态由管理器提供，不从当前控件反推。日志过滤依据设备 ID，而非显示名称。窗口布局属于项目中的版本化可选字段，损坏布局回退默认，不影响协议配置。

复用现有协议表单与服务端 pane，先完成单窗口组合，再改善拖拽/布局恢复。遵循现有 Qt 风格，表格保持键盘可达及明确空态。

## 验收

同一工作区观察两个客户端及两种监听；切换后台运行连续；异常统计可定位设备；重开恢复布局但不自动运行；取消关闭保留全部会话。验证窄窗口、长设备名和高 DPI。
