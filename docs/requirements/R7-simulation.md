# R7 服务端场景模拟

## 目标与依赖

依赖 R2、R5、R6。让服务端按可保存规则产生动态值，供外部客户端联调。

## 功能

固定值、周期递增、心跳翻转、斜坡和正弦；按相对时间执行赋值动作；启动、暂停、重置场景。规则可关联命名点位，带初值、周期、幅度、上下限等参数。

## 运行规则

明确区分方案初始值、运行当前值和场景控制状态。首版每点只允许一个场景写入源；手动修改或客户端写入后该点进入接管状态，需明确恢复自动模拟。暂停冻结场景时钟，重置恢复初始值；停止监听一并停止模拟任务。

## 实现

使用可注入单调时钟驱动规则执行器，通过 R5 的运行值接口写入，不直接触碰 UI 或底层内存。先预校验整套规则，越界时停止相关规则并发出错误，不循环写入无效值。保存规则但不保存运行计时和随机状态。

## 验收

用“启动位→延迟反馈→转速爬升”时间轴验证；两个协议读取动态值正确；手动接管不被下一 tick 覆盖；暂停/重置可预测；关窗无遗留任务。时序测试使用虚拟时钟。
