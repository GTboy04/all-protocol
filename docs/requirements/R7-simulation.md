# R7 服务端场景模拟

## 目标与依赖

依赖 R2、R5、R6。让服务端按可保存规则产生动态值，供外部客户端联调。

## 功能

固定值、周期递增、心跳翻转、斜坡和正弦；按相对时间执行赋值动作；启动、暂停、重置场景。规则可关联命名点位，带初值、周期、幅度、上下限等参数。

## 运行规则

明确区分方案初始值、运行当前值和场景控制状态。首版每点只允许一个场景写入源；手动修改或客户端写入后该点进入接管状态，需明确恢复自动模拟。暂停冻结场景时钟，重置恢复初始值；停止监听一并停止模拟任务。

## 实现

使用可注入单调时钟驱动规则执行器，通过 R5 的运行值接口写入，不直接触碰 UI 或底层内存。先预校验整套规则，越界时停止相关规则并发出错误，不循环写入无效值。保存规则但不保存运行计时和随机状态。

## 验收

用“启动位→延迟反馈→转速爬升”时间轴验证；两个协议读取动态值正确；手动接管不被下一 tick 覆盖；暂停/重置可预测；关窗无遗留任务。时序测试使用虚拟时钟。

## 交付记录

2026-11-09 · 已完成。分支 `codex/r7-simulation` 基于 R6 提交 `ac82727`。

- 项目工作区和本地服务端均可打开「场景模拟」。停止监听时配置规则，启动监听后手动启动场景。每种协议的场景独立控制，规则跟随方案点位保存，点位改名时保留规则。
- 每个点位可选一种规则。时间轴在同一相对时钟上使用 `毫秒 = 数值` 的有序动作。固定值、递增、心跳、斜坡和正弦都可设置启动延时。斜坡到达终值后保持，递增超过上限后回到下限。心跳的间隔表示两次翻转之间的时长。执行器按约 20 ms 采样，周期或斜坡时长最短为 20 ms。
- 手动或客户端成功写入时，涉及的点位进入接管，包含对多字点位的部分写入。S7 的位写入按位判断，字节写入覆盖该字节里的相关位。恢复自动模拟时使用场景当前时刻的值。暂停保持当前值并冻结时钟；重置规则点位的初始值、接管和计时。监听停止或窗口关闭会等待定时任务退出。
- 本地方案与项目文件使用同一序列化路径。含规则的 Modbus TCP 方案使用 v3，S7 方案使用 v2，旧方案仍可读取。项目外层继续使用 v3。场景运行状态只保留在当前监听会话。
- 全量 204 项测试通过，含 19 项 R7 专项。使用真实 Modbus TCP 和 S7 客户端验证“启动位 → 150 ms 反馈 → 200 ms 开始爬升”，覆盖部分写入接管、恢复、重置和停止。虚拟时钟验证边界时序，项目界面测试覆盖配置校验、保存与关窗清理。离屏检查了 780 × 620 的项目工作区和场景弹窗。
