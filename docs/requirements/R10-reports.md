# R10 联调记录与报告导出

## 目标与依赖

依赖 R6、R8、R9。把一次联调的配置、操作结果和验证证据交付给同事。

## 交付范围

导出可离线查看的 HTML 报告及 JSON/CSV 原始记录。包括项目名、导出时间/时区、设备与点表摘要、选定时间范围日志、请求统计、故障注入标记和写入验证结果。用户可选择是否包含原始报文。

## 数据与流程

先明确选择范围，再冻结导出快照，生成预览，最后选择文件路径。采样继续进行时报告仍使用同一快照。输出注明记录范围及是否存在日志轮换导致的缺失，不将未记录时段当作成功。

## 实现与边界

导出器消费不可变 DTO，不读取活动 Qt 控件。HTML 转义所有设备名和错误文本，CSV 对公式前缀做安全处理。长导出后台执行，可取消；失败不留下貌似完整的报告。默认不包含本机目录，用户可在预览中检查将导出的地址和报文。

## 验收

双协议混合日志及验证证据可追溯；中文、长字段与异常字符正确呈现；时区明确；导出期间新日志不进入冻结快照；取消或磁盘失败保留已有文件。报告与机器可读记录总数一致。

## 交付记录

2026-11-10 · 已完成。分支 `codex/r10-reports` 基于 R9 验收提交 `09c30a7`。

- 项目工作区提供「导出联调报告…」。选择起止时间与日志来源后冻结快照，分页预览设备、点表、监听配置及记录。报文选项默认关闭。报告采用冻结时的本机时区，历史无时区日志按本机时间解释。
- 报告包为单个 ZIP，内含离线 `report.html`、带范围和统计的 `records.json`，以及便于表格处理的 `records.csv`。三份输出使用相同的记录序号和快照。报告保留故障标记、写入及回读证据，能在原写入包含于报告时跳转到该条记录。
- 客户端按当前项目设备 ID 纳入记录，服务端仅纳入本次工作区内产生的记录。每个来源最多 500 条。报告显示范围内首末条、已知日志轮换与截断，并提示可能的缺失。R10 起本地轮换标记随日志保存。旧版轮换或外部清理的历史边界可能未知。统计按来源分别计算，未记录时段无结论。
- 预览生成及写入报告包在后台执行。保存以同目录临时文件生成完整 ZIP，再原子替换目标。取消和替换失败保留旧文件。HTML 转义动态内容，CSV 防止文本作为公式执行，报告省略目录元数据并遮盖错误中的本机路径。
- 全量 240 项测试通过，含 7 项 R10 专项。覆盖双协议采样期间冻结快照、三种格式条数一致、中文与异常字符、时区、故障及回读证据、日志轮换、取消与文件替换失败。
