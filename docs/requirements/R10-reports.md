# R10 联调记录与报告导出

## 目标与依赖

依赖 R6、R8、R9。把一次联调的配置、操作结果和验证证据交付给同事。

## 交付范围

导出可离线查看的 HTML 报告及 JSON/CSV 原始记录。包括项目名、导出时间/时区、设备与点表摘要、选定时间范围日志、请求统计、故障注入标记和写入验证结果。用户可选择是否包含原始报文。

## 数据与流程

先明确选择范围，再冻结导出快照，生成预览，最后选择文件路径。采样继续进行时报告仍使用同一快照。输出注明记录范围及是否存在日志轮换导致的缺失，不将未记录时段当作成功。

## 实现与边界

导出器消费不可变 DTO，不读取活动 Qt 控件。HTML 转义所有设备名和错误文本，CSV 对公式前缀做安全处理。长导出后台执行，可取消；失败不留下貌似完整的报告。默认不包含本机目录，用户可在预览中检查将导出的地址和报文。

## 验收

双协议混合日志及验证证据可追溯；中文、长字段与异常字符正确呈现；时区明确；导出期间新日志不进入冻结快照；取消或磁盘失败保留已有文件。报告与机器可读记录总数一致。
