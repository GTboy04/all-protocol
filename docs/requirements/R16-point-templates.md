# R16 · 点表批量编辑与设备模板

2026-11-15 · 状态：计划中，尚未实施。

## 目标与依赖

依赖 R1、R2、R6，覆盖 R11/R12 新协议字段。减少同类设备重复配置和大点表维护成本，可作为独立增量插入 R14/R15 的开发间隙。

## 首版范围

- 从 Excel 等表格复制多行文本并粘贴导入，复用现有 JSON/CSV 校验逻辑，预览列映射和逐行错误。
- 批量修改协议适用的站号、地址偏移、倍率、偏置、字序及表级轮询周期；协议不支持的字段不可选择。
- 检查重复、地址覆盖和类型冲突；Modbus 按站号和数据区、S7 按区域/DB/位范围、OPC UA 按命名空间 URI 和类型化标识符判断。
- 将设备连接参数、点表和可选模拟方案保存为带版本的模板；创建实例时填写名称、连接端点及适用的站号。
- 导入或应用模板前展示新增、修改、删除及未变化项，说明匹配依据，默认不删除现有点位。

## 数据与流程

1. 把批量变换和差异计算放在不依赖 Qt 的应用层；所有改动先生成草稿，再完整校验和预览，确认后一次提交。
2. 原始表格作为文本解析，不执行公式。处理空单元格、引号、制表符、换行和中文，沿用各协议现有值语义。
3. 实例化模板时生成新的设备和点位 ID，并重映射内部引用；更新现有配置时保留明确匹配的 ID。匹配不唯一时提示用户选择。
4. 运行中受影响的任务先按现有编辑规则停止或失效，成功提交后由用户决定是否启动；不能在预览阶段改变设备通信。
5. 模板不包含采样值、日志、密码、私钥或可移植的本机证书路径；OPC UA 在目标机器重新绑定本机安全配置。

## 边界

- 地址重叠可能是有意的别名，提示风险但不一律阻止。数值越界、非法类型和无效地址必须阻止提交。
- 轮询周期属于表级配置，界面不暗示每个点位有独立周期。
- 首版不承诺解析厂商专有工程文件，也不做模板在线市场或跨项目实时同步。
- 首版模板更新覆盖连接和点表；模拟方案首版仅用于新实例创建，不隐式覆盖正在监听的服务端方案。

## 验收

- 大量行粘贴、部分错误、批量偏移越界和取消预览均不产生半完成配置；失败保留原点表。
- 四种协议按各自地址语义检查冲突，Modbus 多寄存器类型与 S7 位范围正确计算。
- 同一模板实例化两次身份独立，修改一台设备不影响另一台；导入差异与实际提交一致。
- 项目/模板格式可往返，旧格式继续兼容，模板中不包含本机敏感配置。

## 交付物

批量编辑与差异预览、模板格式与示例、设备实例化入口，以及导入失败和身份隔离测试。
