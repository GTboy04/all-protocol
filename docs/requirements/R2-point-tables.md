# R2 命名点位与点表

## 目标与依赖

依赖 R1。设备不再只能保存一组临时查询，可保存多张命名点表；快速读写继续保留。

## 功能与交互

- 新建、重命名、复制、删除点表；新增、批量编辑和删除点位。
- 点位包含稳定 ID、名称、协议目标、单位、倍率、偏置、说明、显示精度。
- 表格并排显示原始值与工程值，转换公式为 `raw × scale + offset`。
- 点表配置支持 JSON 导入导出及 CSV 批量录入；导入先预览、校验，再整体应用。
- 同地址允许不同命名视图，但写入必须关联确切的协议目标。

## 数据与实现

新增独立 PointDefinition / PointTable；按 R1 设备 ID 关联。协议目标继续使用各自模型，不统一成字符串地址。定义不含运行值；为 R3 独立采样模型预留关联 ID。

项目 schema 升级并提供 v1→v2 迁移。单位等元信息放在通用层，字序和 DB 等放在协议目标内。变换首先只用于显示；工程值写入由 R9 明确规定。

## 边界与失败

拒绝无穷/NaN 倍率与越界协议目标。配置导入失败不留下半张表；点位改地址后清除旧采样关联。删除设备需同时提示关联点表影响。该需求只做单次整表读取，多组轮询由 R3 提供。

## 验收

同一设备两张表可切换并保存重开；双协议目标无损恢复；工程值正确且原始值可见；坏 CSV 能定位行号；取消删除和导入不改项目。
