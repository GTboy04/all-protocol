# R2 命名点位与点表

## 目标与依赖

依赖 R1。设备不再只能保存一组临时查询，可保存多张命名点表；快速读写继续保留。

## 功能与交互

- 新建、重命名、复制、删除点表；新增、批量编辑和删除点位。
- 点位包含稳定 ID、名称、协议目标、单位、倍率、偏置、说明、显示精度。
- 表格并排显示原始值与工程值，转换公式为 `raw × scale + offset`。
- 点表配置支持 JSON 导入导出及 CSV 批量录入；导入先预览、校验，再整体应用。
- 同地址允许不同命名视图，但写入必须关联确切的协议目标。

## 数据与实现

新增独立 PointDefinition / PointTable；按 R1 设备 ID 关联。协议目标继续使用各自模型，不统一成字符串地址。定义不含运行值；为 R3 独立采样模型预留关联 ID。

项目 schema 升级并提供 v1→v2 迁移。单位等元信息放在通用层，字序和 DB 等放在协议目标内。变换首先只用于显示；工程值写入由 R9 明确规定。

## 边界与失败

拒绝无穷/NaN 倍率与越界协议目标。配置导入失败不留下半张表；点位改地址后清除旧采样关联。删除设备需同时提示关联点表影响。该需求只做单次整表读取，多组轮询由 R3 提供。

## 验收

同一设备两张表可切换并保存重开；双协议目标无损恢复；工程值正确且原始值可见；坏 CSV 能定位行号；取消删除和导入不改项目。

### 数据与迁移

`point_tables.py` 提供 PointDefinition、PointTable 和协议目标编解码。每个命名点位仅对应一个标量（count=1），连续地址批量添加通过 CSV 完成。表关联稳定 device_id；表和点位 ID 全项目唯一；复制或导入创建新 ID，普通编辑保留 ID。同地址可有多个不同名称。

项目 v2 在顶层加入 point_tables；打开 v1 得到空点表，下一次显式保存写成 v2。读取不改源文件，v1 文件中夹带非空点表会被拒绝，防止静默丢弃。设备删除同时删除其点表，确认弹窗显示关联表数量。

### 界面方案

沿用深蓝 `#142a40` 标题、浅灰蓝 `#edf2f6` 工作区、白色表格和青色主操作；微软雅黑 UI 用于文本，等宽字体仅用于协议字节。客户端中部采用「快速读写 / 点表」页签，下方保留请求日志。

点表顶部为当前设备与表选择，第一行管理表及导入导出，第二行管理点位及读取/写入。名称和地址左对齐，原始值与工程值右对齐；单位单列，转换规则和读写语义放在底部。没有设备时明确提示填写并保存设备配置，不要求先联网。

编辑点位复用既有协议地址表单；工程值计算采用十进制数值路径，避免 UInt64 默认倍率时损失整数精度。单点「写入原始值」沿用现有确认弹窗，不进行工程值反算。

### 导入与批量编辑

JSON 使用独立 `all-protocol-point-table` 格式（schema_version=1），校验当前设备协议，预览确认后新增表。CSV 文件以 UTF-8（可带 BOM）输入；批量编辑器也使用 CSV，先「校验并预览」再「应用整表修改」。修改输入会使先前预览失效。

CSV 必需列：`name,area,address_offset,data_type`。可选列：`id,unit,scale,offset,precision,description,unit_id,db,bit,order`。address_offset 表示协议地址；offset 表示工程偏置。Modbus Unit ID 默认 1、order 默认 big；S7 DB 区默认 DB1，其他区 DB0；bit 默认 0；倍率 1、偏置 0、精度 3。错误包含 CSV 行号；未知列、重复 ID、非法地址、NaN/Infinity 整体拒绝。文件导入重新分配 ID，批量编辑保留 CSV 中已有 ID。文件上限 10 MiB。

### 单次整表读取

Session.execute_table 在当前连接上串行读取冻结的命令序列，用 table_id/point_id 关联结果。每点保留独立请求日志及 TX/RX；普通超时或异常不阻断后续点，断开则取消剩余任务。读取期间禁止编辑配置和启动其他操作，不建立后台轮询组。

采样只在界面内存中保存。点位地址变化后清除对应采样，断开后已有值显示旧数据；完整质量状态和定时过期由 R3 承接。表读取结果不会覆盖快速读写结果。

### 开发顺序

1. 点位/点表模型、类型校验、JSON/CSV 编解码。
2. 项目 v2 与 v1 迁移、关联校验和设备删除级联。
3. 点表 CRUD、单点编辑、CSV 预览及配置导入导出。
4. 单次整表读取、原始值确认写入、日志关联与采样清除。
5. 模型失败路径、Qt 流程、双协议读写及完整回归；截图检查布局。
