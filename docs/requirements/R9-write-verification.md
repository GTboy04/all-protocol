# R9 写入回读验证

## 目标与依赖

依赖 R3、R4。用户可选择写后回读，明确区分设备应答与值验证。

## 流程

确认写入目标、原始值和工程值→提交写请求→记录应答→可选延迟回读→比较→呈现证据。写入已应答、已拒绝、结果未知与回读一致、不一致、无法验证分开显示。

## 规则

- 未知结果不得自动重发；用户主动核对时执行独立读取。
- 整数和 Bool 精确比较，浮点使用明确可配置的绝对/相对容差。
- 工程值写入需反向转换，scale 为 0 时禁止，整数不得静默截断。
- 验证读关联原写请求，并在队列内保持定义好的相邻顺序；不承诺设备值在验证前不会被外部修改。
- I/IR/DI 等只读规则继续由协议适配器执行。

## 实现与失败

新增 WriteResult / VerificationResult，保留原始应答、回读时间和值；不靠日志文案反推状态。断开、取消、回读超时只终止验证，不改变已发生写入的事实。

## 验收

覆盖一致、不一致、写拒绝、写超时但实际成功、回读超时、浮点容差和倍率反算；任何路径不重复写。Qt 界面能独立说明应答结果和验证结果。
