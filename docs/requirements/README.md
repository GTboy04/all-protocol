## 开发与分支约定

- 当前需求分支为 `codex/r7-simulation`，基于 R6 提交 `ac82727`。R1–R6 分支保留用于回看验收。
- 后续每项使用独立 `codex/rN-主题` 分支，基于前置需求已验收的代码开始；不切换到缺少依赖的基线。
- 原有 S7 和多协议服务端工作已单独保存为 `16c12ab`，保护分支 `codex/s7-workbench-baseline`；未与 R1 混为一笔提交。
- 任务结束提供变更范围和测试结果；提交、合并时检查暂存区，避免混入已有改动。
- 无需为文案等低影响改动增加测试；配置格式、调度、协议语义与资源释放必须覆盖有意义的失败路径。

## 版本边界

R1–R4 构成第一阶段；R5–R8 构成模拟与排障阶段；R9–R10 构成交付验证阶段。新增协议、任意脚本执行、云同步、网关转发不纳入本路线。
