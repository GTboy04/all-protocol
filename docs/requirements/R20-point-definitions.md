# R20 · 点位功能描述与搜索定位

2026-11-15 · 状态：软件已实现，与 R13 同阶段交付。依赖 R2、R6，兼容 Modbus TCP / RTU、S7 和 OPC UA 命名点表。

## 目标

让点位除了地址和名称，还能明确说明“这个点位有什么功能、可以做什么”，并通过描述查找到对应点位。

## 本次实现

- 将点位编辑框中的“说明”升级为多行“功能描述”，提供用途、取值含义、操作注意事项的填写提示，不强制模板格式。
- 表格显示功能描述，悬停可查看全文；选中点位后，右侧只读面板完整显示名称、协议地址和描述，可复制阅读，分隔条可拖动调整宽度。双击点位进入编辑。
- 搜索名称、界面显示的协议地址/类型和功能描述。忽略英文字母大小写，空格分隔多个关键词时须全部匹配。
- 当前点表仅显示匹配行；定位下拉框检索当前设备的所有点表，选择结果切换点表并选中具体点位。切换设备时结果范围随设备切换。
- 搜索只改变视图，不改变配置顺序、点位身份、采集范围或“读取整表”的范围。筛掉当前选中点位时清空选择，避免写入隐藏行。
- 复用已有 `description` 字段，旧项目、点表 JSON 和 CSV 中的说明无需迁移。换行、逗号、引号和中文可完整往返；项目保存、复制和导入导出均保留说明。HTML/JSON 报告包含功能描述，HTML 按文本转义。

示例：

```text
用途：控制排风机启动与停止
取值含义：0=停止，1=启动
操作注意事项：写入前检查联锁，运行状态请查看“风机运行反馈”点位
```

## 边界

- 描述由用户定义，不根据地址自动猜测设备含义，也不作为权限、联锁或写入校验依据。
- 首版检索当前设备内的点表，不跨设备或服务端方案搜索。
- 采集中的地址/配置编辑仍遵循现有点表限制；查看描述和搜索无需停止采集。
- 不增加结构化枚举、关联跳转、厂商词典或独立知识库。后续批量编辑与模板沿用本字段，见 [R16](R16-point-templates.md)。

## 验收

- 多行描述编辑后点位 ID 保持不变；项目 SQLite、点表 JSON/CSV 保存再读取内容一致。
- 描述中的文本不会被当作 HTML 执行，报告保留文本含义。
- 名称、地址、描述、多个关键词、无结果、清空搜索和跨点表定位均可用，底层点表顺序不变。
- 选中行被筛掉后，描述面板清空，写入按钮不可用；采样刷新不会清除搜索条件或重新排序。

实现与验证入口见 [R13 阶段交付记录](../r13-runtime-reliability.md)。
