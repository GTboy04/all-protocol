# R8 请求诊断与故障注入

## 目标与依赖

依赖 R3、R5、R7。将原始报文与请求结果关联起来，并可主动复现联调故障。

## 诊断功能

按设备、时间、操作和错误筛选日志；选中请求显示协议字段树、原始十六进制及字节高亮。展示窗口内请求数量、失败比例、平均/分位耗时；明确统计窗口和剔除项。

## 故障功能

模拟服务支持匹配规则：下一次/指定次数/持续时间的响应延迟、异常响应、主动断开。首版只提供明确模板，不做任意畸形字节编辑。故障状态在服务视图持续可见，停止或重置清除运行计数。

## 实现与边界

协议解码器只解释捕获数据，解析失败保留原始帧并定位失败位置。请求与报文使用 R4 唯一会话 ID + 请求 ID 关联；被动日志查看不触发网络请求。故障执行在 R5 适配器边界，延迟任务可取消。

## 验收

标准帧字段偏移正确；残缺帧不使界面崩溃；筛选与统计口径一致；一次性故障只影响一次；停止延迟服务释放连接；大量日志不阻塞采样。未知写入结果不能被显示成已拒绝。
