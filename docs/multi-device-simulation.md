# 多设备模拟

项目工作区的左侧提供「添加设备」和「添加模拟设备…」。前者添加要连接的远程设备，后者在本机增加一个独立运行的模拟服务。同一项目最多配置 64 个模拟服务，每个服务的点位、当前值、场景、故障、请求日志和启停独立。

| 协议 | 模拟多设备的方式 |
| --- | --- |
| S7 | 每台 PLC 添加一个独立模拟服务，使用不同 IP 或端口。相同地址的点位互不影响。Rack/Slot 不用于划分模拟设备。 |
| Modbus TCP | 独立网络设备使用独立监听端点；模拟网关后面的多台设备时，在同一个服务内「新增从站…」，用 Unit ID 区分。 |
| Modbus RTU | 同一总线使用一个串口服务，通过不同站号模拟多台设备；另一条总线才添加独立服务，并选择另一串口。 |
| OPC UA | 独立服务器使用独立端口，各自有独立节点、会话和订阅。保留本机回环与显式选择模拟模式的限制。 |

添加对话框会建议当前项目尚未使用的端口或 COM 名称，并检查已配置的监听地址 / 串口冲突。对话框不会自动分配网卡地址，也不保证端口没有被外部程序占用；操作系统拒绝监听时，仅该设备报错，其他设备继续运行。手动修改已有设备端点后，同样由操作系统检查占用。

例如添加三台 S7，可使用 `127.0.0.1:1102`、`:1103`、`:1104`。客户端分别连接对应端点。局域网联调请使用本机已配置的网卡 IP；若上位机只支持 TCP 102，应给电脑配置不同 IP，再分别绑定各 IP 的 102 端口。避免将服务绑定在 `0.0.0.0` 后又在同端口添加一个 IPv4 地址服务。

选中模拟设备后可「重命名…」「复制设备…」「删除设备…」。复制保留初始值、点位顺序、Bit 含义、模拟规则和权限，使用新的监听端点；运行时当前值不作为初始值复制。删除前须停止该设备的服务，其他设备可以继续运行。Modbus 视图另有「新增从站…」入口，运行期间不可新增。所有修改需点击「保存项目」。重新打开项目不会自动启动监听。删除全部模拟服务后不会重新生成默认设备。

旧项目仍能打开，保留每种协议原有的默认服务。首次添加、删除或重命名模拟设备后，项目使用 v8：`simulators` 列表保存每个模拟服务的 ID、名称、协议和完整方案。SQLite 将列表存于 `metadata` 的 `simulators` 项，原有客户端设备、点表和旧方案表保持兼容；旧版程序会拒绝 v8 项目，建议另存一份。各实例的会话日志在本次工作区独立保留，报告按实例分别输出，避免加载其他项目的协议历史日志。

协议依据：Modbus 的 Unit Identifier 用于同一网关下多台终端的路由，见 [Modbus TCP 实现指南](https://www.modbus.org/docs/Modbus_Messaging_Implementation_Guide_V1_0b.pdf)。OPC UA 也允许在同一服务器的地址空间组织多个设备，见 [OPC UA Devices 规范](https://reference.opcfoundation.org/specs/OPC-10000-100/full)；本功能针对独立服务器联调采用独立端点，现有节点仍可在各自服务器中管理。
