# S7 客户端设计

## 范围

在客户端协议选择器加入「Siemens S7（ISO-on-TCP）」。首版用于对 PLC 的绝对地址做单次读写和轮询，支持经典 S7comm。验证使用本机模拟端，现场 PLC 兼容性需按具体 CPU 和固件联调。应用内的模拟端见 [多协议服务端设计](multi-protocol-server-design.md)。

## 连接和点位

- 主机、端口（默认 102）、Rack（0–7，默认 0）、Slot（0–31，默认 1）、超时（默认 3000 ms）。采用 PG 连接，远端 TSAP 为 `0x0100 | (rack << 5) | slot`。同一主机端口的不同 Rack/Slot 各自保存最近连接。
- TCP、COTP Connect Confirm、S7 Setup Communication 全部成功后显示已连接。整个握手使用一个超时。连接协商上限 480 字节。单次业务操作只发一个 S7 请求，并按协商后的 PDU 和 TPDU 大小检查容量。
- 支持 DB、M、I、Q 区，I 区在工作台只读。DB 号范围 1–65535，其余区域用 0。字节偏移从 0 开始，末字节不得超过 2097151（24 位位地址可表示的范围）。实际可用地址取决于 PLC。
- Byte、Int、Word、DInt、DWord、Real 用连续字节传输，分别按 1、2、2、4、4、4 字节大端解码。单次最多 200 字节。Bool 用字节偏移加 0–7 位索引，每次一个点，写入使用原生位写请求。结果表同时显示解析值和原始数据。
- 写入确认弹窗显示端点、地址范围及待写值。适配器再次校验权限、数量和取值范围，Real 仅接受可表示的有限值。确认成功表示设备应答，可通过重新读取核对。

## 实现和故障处理

- 在 `adapters/s7` 实现地址模型和 asyncio 客户端。TPKT 负责 TCP 流拆帧，COTP 负责握手和数据传输，S7 层核对响应引用号、功能码、项目数、状态及数据长度。仅实现本功能使用的报文，保留实际 TX/RX 帧，不引入生产依赖。
- 复用客户端会话、请求串行、轮询、写入确认状态及本地日志。连接和点位表单独立注册，历史使用协议键 `s7`。读写日志保存完整 TPKT 帧。
- 明确的设备拒绝保留 S7 错误码，连接仍可使用。响应超时、掉线或报文无效时关闭连接，避免迟到帧与后续请求混淆。写请求一旦发送，缺少有效确认则标记「写入结果未知」，无自动重试。
- S7-1200/1500 使用前按设备配置启用 PUT/GET，并为要绝对寻址的 DB 使用标准（非优化）块访问。Rack 和 Slot 以设备配置为准。 [西门子 PUT/GET 手册](https://docs.tia.siemens.cloud/r/simatic_s7_1200_manual_collection_enus_20/communication/s7-communication/get-and-put-read-and-write-from-a-remote-cpu)

## 开发前自检

| 检查项 | 结论及开发后的验收方式 |
| --- | --- |
| 分支及兼容性 | 将 `feature/modbus` 的 `743f60c` 合入 `main` 后切出 `codex/s7`。注册接口已有多协议切换能力，现有 Modbus 工作台和历史格式继续适用。 |
| 地址与边界 | 界面与适配器共用类型宽度、偏移和写权限规则。验证越界、I 区写入、字节序和 Bool 单位。 |
| 会话和故障 | 使用现有的在途任务管理。用独立协议模拟端验证连接、读写和协议拒绝，用可控对端验证碎片、无效应答、超时和写入只发一次。 |
| 使用入口 | 从桌面客户端选择 S7。验证最近连接恢复、轮询、结果和报文显示，并运行 Windows 打包。 |
